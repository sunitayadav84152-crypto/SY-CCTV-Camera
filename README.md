# SY CCTV Camera - Web Front-End

A clean, modern, and responsive web front-end interface designed for a CCTV surveillance and security systems business.

## Features
* **Modern UI/UX:** Built with clean HTML5 and CSS3 styling.
* **Product Showcase:** Displays popular security camera models (Dome, Bullet, and Wi-Fi PTZ).
* **Interactive Inquiry Form:** Instant feedback interaction using JavaScript.
* **Fully Responsive:** Adapts smoothly across desktop and mobile screens.

## Technologies Used
* **HTML5** (Structure)
* **CSS3** (Styling & Layout)
* **JavaScript** (Interactivity)

## Project Preview
You can view the static front-end structure by cloning this repository or opening `index.html` in any web browser.
